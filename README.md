# Anime Finder

Anime Finder is a responsive web application for searching anime and generating random anime recommendations using the Jikan API. Search results display information including the anime's rating, cover image, trailer availability, and a link to its MyAnimeList page.

## Features

- Search for anime by name
- Generate a random anime
- View anime ratings and cover images
- Open available anime trailers
- View anime pages on MyAnimeList
- Clear search results and start a new search
- Search using the Enter key
- Responsive layout for desktop, tablet, and mobile devices
- Handles missing images, trailers, ratings, empty searches, and API errors

## Built With

- TypeScript
- HTML
- CSS
- [Jikan API](https://jikan.moe/)
- Fetch API
- Vite

## API

Anime Finder uses the [Jikan API](https://jikan.moe/), an unofficial MyAnimeList API, to retrieve anime data.

Because the application relies on an external API and its upstream data source, anime data may occasionally be temporarily unavailable.
